Prédiction de la qualité de l'air à Montréal

Julia · 01/2026 – 04/2026 · équipe de 5 · 95/100 · MTH3302

Prédire la concentration journalière de particules fines (PM) sur 7 stations montréalaises pour les 365 jours de 2025, soit 2 555 prédictions, à partir de 17 ans de données.

  • Jointure air + météo, analyse exploratoire, 20+ variables dérivées (moyennes mobiles, saisonnalité sinus/cosinus, interactions température × mois)
  • Valeurs manquantes traitées par variable ; validation par séparation temporelle, jamais aléatoire
  • 4 variantes comparées ; modèle retenu : régression linéaire (GLM.jl, 23 variables) sans variable construite sur le PM passé, pour éviter la propagation d'erreur
  • RMSE de 18,25 sur Kaggle ; limites documentées : sous-estimation des épisodes de fumée
  • Séries temporelles
  • Régression linéaire
  • Feature engineering
